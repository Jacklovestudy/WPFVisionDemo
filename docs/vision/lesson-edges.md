# 基础边缘检测

选择照片，点击“边缘检测（差值 > 50）”。每次从整张原图开始：转灰度 → 3×3 均值滤波 → 比较右/下灰度差 → 输出黑白边缘图。

## 核心代码

GrayImageProcessor.DetectEdges 单独负责差分判断，输入二维灰度数组。

- x 是行，y 是列。
- 右邻居为 gray[x,y+1]，下邻居为 gray[x+1,y]。
- Math.Abs 取绝对值，所以由暗到亮、由亮到暗都能检测。
- 任意方向差值严格大于阈值，result[x,y] 输出 255，否则输出 0。
- 最后一列跳过右方，最后一行跳过下方；不存在的邻居不参与比较。
- 始终读取原数组，写入新的结果数组。

ImageFileLoader.DetectEdges 负责图片适配及滤波，ShowLoadedEdges 负责按钮显示。可修改其中的 threshold = 50 来比较结果：降低阈值会标出更多或相同数量的边缘候选点。

## 理解结果

二值化看像素自身亮度；边缘检测看相邻像素的变化。均值滤波可以减弱噪点，也会减弱真实边缘。固定阈值 50 可能漏掉弱边缘。

这是学习用的右/下相邻差分，不是完整的轮廓识别。文字、阴影、反光、纹理也能产生白色边缘。原图缩小显示时细边缘可能不明显。
