# 3×3 均值滤波

使用：选择图片 → 均值滤波（3×3）。对比“转灰度”观察平滑效果；对比“二值化（100）”与“滤波后二值化（100）”观察处理顺序的影响。这两个新按钮处理整张原图，每次从原图开始，不会累计模糊。

## 算法：GrayImageProcessor.MeanFilter3x3

1. 输入二维灰度数组，x 是行，y 是列。
2. 外面两层循环逐个选择中心像素。
3. 每个中心重新设置 sum、count 为 0。
4. 里面两层循环遍历中心周围的 3 行、3 列，包含中心自己。
5. 越界位置 continue 跳过；有效位置累加灰度并增加计数。
6. result[x,y] = (byte)(sum / count)，整数除法舍去小数。
7. 始终读原数组、写新数组，避免前面的修改影响后面。

宽高至少为 3 时：内部通常除以 9，边缘非角落除以 6，角落除以 4。小图也按实际有效数量计算。

例子：中心 100，周围八个 10，中心输出为 (100 + 8 × 10) / 9 = 20。

## 图片适配：ImageFileLoader.MeanFilter3x3

照片先转 Gray8，CopyPixels 读出一维灰度数组，再按 x * width + y 还原二维数组。调用核心算法后 Flatten 平铺，生成新的 BitmapSource 显示。

均值滤波计算的是灰度平均值，不是中心坐标。图像尺寸不变；细碎变化减弱，但边缘也可能变模糊。它不保证把杯子从背景中完整分离。大照片缩小显示时，3×3 的变化可能不明显。
