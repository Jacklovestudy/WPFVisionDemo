# 视觉知识体系

来源：Codex 任务“视觉”（01a08404-bec7-7c23-8a08-6bd5cf27d60a），2026-09-09 整理。

以下保留该阶段的教学内容；当前项目的技术栈及进度见 [学习进度](progress.md)。文中的练习建议不代表已经实现或完成。

---

明白，你要的是**机器视觉本身的完整知识体系：知道图像怎么形成、算法为什么有效、什么情况下会失效，并能自己实现和验证。** C# 是你的实践语言，海康只是你接触过的工具。

下面按“零基础 → 核心原理 → 综合应用 → 深入研究”的顺序整理。它以工业视觉为主要应用方向，同时覆盖通用计算机视觉基础。

## 一、图像与成像基础

先弄清楚“图像是什么、怎么来的”。

| 知识点 | 要理解的问题 |
|---|---|
| 像素、分辨率、坐标 | 图像怎样表示，某个点在哪里 |
| 灰度、位深、动态范围 | 数字如何表示亮暗，能表示多少层次 |
| 通道、RGB、HSV 等颜色空间 | 颜色怎样表示，不同表示有什么用途 |
| 图像内存、行跨度 | 图像在程序里怎样存储和访问 |
| 采样、量化 | 连续世界如何变成离散数字 |
| 直方图 | 图像的亮度分布有什么特点 |
| 噪声、对比度、饱和 | 什么因素让信息难以辨认或丢失 |
| 曝光、增益、运动模糊 | 拍摄参数怎样影响图像 |
| 焦距、视野、工作距离、景深 | 镜头怎样决定拍摄范围和清晰程度 |
| 光源、反射、透射、畸变 | 为什么同一个物体能拍出完全不同的效果 |

**实践目标：** 能查看像素、解释图像变亮或模糊的原因，并估算目标在图像中占多少像素。

## 二、基础图像处理

学习如何根据规则改变图像。

- **点运算：** 亮度、对比度、归一化、Gamma 变换。
- **直方图处理：** 直方图均衡化及其局限。
- **邻域与卷积：** 卷积核怎样参与计算，边界怎样处理。
- **滤波：** 均值、高斯、中值、双边滤波。
- **几何处理：** 裁剪、缩放、旋转、插值。
- **阈值分割：** 固定阈值、Otsu、局部自适应阈值。
- **形态学：** 腐蚀、膨胀、开闭运算、结构元素。

**核心问题：** 一个处理步骤保留了什么信息，又损失了什么信息？

**实践目标：** 用 C# 自己写灰度阈值处理、均值滤波和简单腐蚀，逐像素检查结果。

## 三、区域、轮廓与形状分析

学习如何从像素变成“一个物体”。

- 四邻域、八邻域与连通性。
- 连通域标记。
- 区域和轮廓的区别。
- 面积、周长、质心、包围框。
- 图像矩、方向、长宽比、圆度。
- 凸包、凸缺陷。
- 孔洞、距离变换。
- 分水岭及粘连目标分离。

**实践目标：** 对物体计数，区分大小和形状，理解粘连、孔洞和噪点为什么会改变结果。

## 四、边缘、特征与几何拟合

学习如何提取稳定的位置和结构。

- 一阶导数、二阶导数与图像梯度。
- Sobel、Laplacian、Canny 的基本原理。
- 边缘方向、强度、极性。
- 亚像素边缘定位。
- 直线、圆、椭圆拟合。
- 最小二乘与 RANSAC。
- 霍夫变换。
- 角点及局部特征描述子的基本思想。

**实践目标：** 从有噪声的图像中找出直线和圆，并比较不同方法对干扰的敏感程度。

## 五、定位、匹配与图像配准

学习如何判断“它在哪里，两张图怎样对齐”。

- 模板匹配：差值、相关性、归一化相关性。
- 基于边缘或形状的匹配思想。
- 图像金字塔、多尺度搜索。
- 平移、旋转、尺度变化。
- 特征点检测、描述、匹配与错误匹配剔除。
- 刚性、相似、仿射、透视变换。
- 单应矩阵。
- 图像配准及变换后的重采样。

**实践目标：** 找出移动或旋转的目标，将两张图对齐，并解释光照、遮挡、重复纹理为什么会造成匹配失败。

## 六、相机几何、标定与测量

学习如何把图像位置和真实世界联系起来。

- 针孔相机模型。
- 世界、相机、图像和像素坐标系。
- 相机内参、外参。
- 径向畸变、切向畸变。
- 标定、重投影误差。
- 平面尺寸测量。
- 透视、物体高度变化对测量的影响。
- 误差传播、系统偏差、重复性。
- 手眼标定：需要机器人应用时深入。

**实践目标：** 完成标定和尺寸测量，并能说明测量成立的条件，以及精度受到什么限制。

## 七、频域、多尺度与纹理

这一部分可以在掌握前面内容后深入。

- 傅里叶变换的直观含义。
- 空间域与频域。
- 高频、低频与滤波。
- 混叠、采样定理。
- 高斯金字塔、拉普拉斯金字塔。
- 纹理特征，例如 LBP、Gabor。
- 形状信息与纹理信息的区别。

**实践目标：** 理解周期性干扰、重复纹理和图像细节，并尝试纹理缺陷检测。

## 八、传统视觉任务与方法选择

把已有原理组合起来解决问题：

| 任务 | 主要涉及知识 |
|---|---|
| 数量、有无检测 | 分割、连通域、特征筛选 |
| 尺寸测量 | 边缘、几何拟合、标定 |
| 缺口、划痕、污渍检测 | 成像、差分、形态学、纹理 |
| 颜色判断 | 颜色空间、颜色一致性 |
| 字符识别 | 分割、特征、分类、序列识别 |
| 运动分析 | 帧间差分、背景建模、光流、跟踪 |

**实践目标：** 能针对一个问题提出几种方法，说明选择理由，并分析各自的失败条件。

## 数学按这个顺序补

| 顺序 | 数学内容 | 主要用途 |
|---|---|---|
| 1 | 函数、坐标、三角函数 | 理解图像和几何关系 |
| 2 | 向量、矩阵、线性方程 | 变换、拟合、标定 |
| 3 | 均值、方差、概率、分布 | 噪声、统计、效果评估 |
| 4 | 导数、偏导、梯度 | 边缘、优化、学习算法 |
| 5 | 最小二乘、数值优化 | 拟合、标定、模型训练 |
| 6 | 信号与傅里叶分析 | 采样、滤波、频域处理 |

不用先学完数学再碰图像。**遇到具体问题时补数学，再回到图像验证，理解会更牢。**

## 怎样才算真正掌握一个知识点

每学一个算法，都检查自己能否做到：

1. **用自己的话解释：** 它解决什么问题？
2. **手算小例子：** 给一个 `5×5` 的像素矩阵，能否算出结果？
3. **实现核心过程：** 用 C# 写出简化版本。
4. **与成熟实现比较：** 差异在哪里，为什么？
5. **设计失败案例：** 什么输入会让它失效？
6. **定量验证：** 准确度、误差、耗时如何？

不需要把所有复杂算法都从头实现，但阈值、卷积、形态学、连通域、简单几何变换这些基础，亲手写一次很有价值。

**你当前的学习起点是第一部分。第一个阶段目标是：能把图像看成数字，理解坐标和亮度，并亲手完成阈值分割。** 后续依次推进到区域分析、边缘、定位和测量；不要一开始同时铺开深度学习和 3D。
