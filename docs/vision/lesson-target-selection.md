# 按条件选择目标

选择照片，可先框 ROI，展开“目标筛选参数”，然后点击“按条件选目标”。旧的“提取照片轮廓”仍然只选面积最大的一块，便于对比。

## 参数

- 最小面积：白色像素数，不是外接矩形面积。
- 宽高比：外接矩形宽 / 高，使用小数。
- 填充率：区域面积 / 外接矩形面积；60% 输入 0.6。
- 预期行、列：ROI 模式下使用 ROI 内坐标，否则是原图坐标。空白自动取该方向中心索引。
- 最大距离：原图像素单位，不是屏幕显示距离。

默认面积 100、宽高比 0.4～0.7、填充率 0.6、最大距离 100，仅为课堂练习初值，不保证适用于杯子照片。

## 算法

TargetSelector.Select 逐个计算区域特征，先排除面积、比例、填充率不合格的区域，再计算质心到预期位置的距离平方，排除超出最大距离的区域，最后选择距离最近的。同距离选逐行扫描先找到的；没有合格区域返回 null，不回退到最大目标。

界面显示总区域数量、面积/形状合格数量、距离合格数量，以及最终目标的比例、填充率和距离。橙色外轮廓仍映射回原图，红点仍是轮廓行进位置，不是质心标记。

当前二值化仍为灰度 < 100 时输出白色；筛选条件只能筛选现有区域，不能修复错误分割。
