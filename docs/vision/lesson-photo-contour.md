# 从照片追踪外轮廓

## 使用

选择图片 → 框选 ROI（包含整个杯身、杯把并留少量余量）→ 二值/开闭运算预览 → 提取照片轮廓 → 轮廓下一步。二值预览现在保留 ROI，可直接继续提取。

有 ROI 时只搜索框内区域；没有 ROI 时处理全图。上方会注明处理范围。重复提取保留同一个选框，框内无前景不会退回全图。目标碰到选框边缘时提示可能出现裁剪边界。

程序按“灰度小于 100 为白，否则为黑”进行二值化，找出面积最大的白色四连通区域，然后自动追踪该区域的外轮廓。橙色线叠加在原图上，红点显示当前位置。每点下一步，沿原图的一个像素边长前进，最后回到起点时禁用下一步。重新提取可重新开始。

## 与方框演示的区别

方框演示使用预设 A～H 路径；照片轮廓由真实像素计算。ContourTracer.TraceOuterContour 沿像素方格外侧追踪，坐标是网格顶点，不是像素中心索引。例如单个像素也有四条外边，能形成闭合路径。

## 方法步骤

1. 将最大区域的像素存入集合，便于检查上下左右邻居。
2. 白点某一侧没有同区域白点，该侧就是边界边。
3. 给边界边规定方向，让白色始终在行进方向右侧。
4. 从最上、最左白点的上边开始，避免从内部孔洞开始。
5. 到每个顶点后，依次检查右转、直行、左转、回头，选择存在的有向边。
6. 回到相同的起点和方向时结束，而不是遇到任意走过的点就停止。
7. 若使用 ROI，先把小图轮廓的行加上 ROI 起始行、列加上 ROI 起始列，再根据完整原图尺寸与界面留白映射到叠加层。显示的坐标始终基于原图。

## 范围

当前只显示最大白色区域的外轮廓，不枚举孔洞，不做杯子识别。背景若连成最大区域，也会被选中；可以先查看普通二值化结果理解原因。此流程不使用之前可能断开的边缘检测结果，也不自动做开闭运算。

照片缩小时，每一步移动可能不足一个屏幕像素，可结合上方坐标和步数观察。边界顶点的最大行/列可以等于图像高/宽，因为它们位于像素外侧，不用于直接访问数组。
