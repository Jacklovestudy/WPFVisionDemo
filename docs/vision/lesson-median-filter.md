# 3×3 中值滤波

选择图片后，点击“中值滤波（3×3）”查看灰度结果，点击“中值后二值化（100）”查看先滤波再二值化的结果。两个按钮每次都处理整张原图，不累计滤波；可以切回原图、均值滤波或普通二值化对比。

## 核心方法：GrayImageProcessor.MedianFilter3x3

1. 外层两层循环选中中心像素，x 是行，y 是列。
2. values.Clear() 清掉上一个中心的邻域数据。
3. 内层两层循环遍历周围 3×3，包含中心自己；越界位置跳过。
4. values.Add(gray[row,col]) 收集原图中的有效灰度值。
5. values.Sort() 按灰度排序，不移动原图像素的位置。
6. 奇数个取 values[count / 2]；偶数个取中间两个值的平均，整数除法舍去小数。
7. 结果写入 result[x,y]，原图保持不变。

例如 9 个数排序后取第 5 个，索引是 4。角落只有 4 个值 10、20、40、50 时，输出 (20+40)/2=30。

## 图片和界面

ImageFileLoader.MedianFilter3x3 负责照片转灰度、读出像素、还原二维数组、调用算法，再平铺生成 WPF 图片。ViewModel 的 ShowLoadedMedian 与 ShowLoadedMedianBinary 分别显示灰度结果、二值结果。

## 与均值滤波对比

均值取全部有效值的平均，中值排序后取中间值。中值适合孤立的黑白噪点，但也可能消除真实的小点缺陷。滤波不能自动区分噪声和真实细节。原图缩小显示时，3×3 的效果可能不明显。
