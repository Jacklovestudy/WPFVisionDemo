### 1. 先把灰度图理解成二维数组

先研究只有黑、白、灰的图像，叫作**灰度图**。

下面这个数字表，就可以表示一张宽 5 像素、高 4 像素的灰度图：

```text
220  220  220  220  220
220   30   30   30  220
220   30   30   30  220
220  220  220  220  220
```

每个数字对应一个小格子，这个小格子叫**像素**。

在常见的 **8 位灰度图**中：

- `0` 表示黑色。
- `255` 表示白色。
- 中间的数值表示不同程度的灰色，数值越大越亮。

所以，上面的图像显示出来，会是**浅色背景中间有一块深色区域**。

注意：像素是图像中的一个采样位置，数字是它的灰度值。程序最初只有这些数据，还不知道哪里是“零件”。

### 2. 为什么是 0～255？

因为我们用 8 个二进制位存储一个灰度值：

```text
00000000 → 0
11111111 → 255
```

一共可以表示：

```text
2⁸ = 256 种数值
```

这正好对应 C# 中的 `byte`。

因此，可以先用下面的数组表示刚才的图：

```csharp
byte[,] gray =
{
    { 220, 220, 220, 220, 220 },
    { 220,  30,  30,  30, 220 },
    { 220,  30,  30,  30, 220 },
    { 220, 220, 220, 220, 220 }
};
```

这是学习用的表示方式。实际图像库可能使用连续内存和行跨度等方式存储，后面再学。

### 3. 坐标从左上角开始

通常，图像坐标这样规定：

```text
            X 向右增加 →
         0    1    2    3    4
       ┌────┬────┬────┬────┬────┐
Y  0   │220 │220 │220 │220 │220 │
向     ├────┼────┼────┼────┼────┤
下 1   │220 │ 30 │ 30 │ 30 │220 │
增     ├────┼────┼────┼────┼────┤
加 2   │220 │ 30 │ 30 │ 30 │220 │
↓      ├────┼────┼────┼────┼────┤
   3   │220 │220 │220 │220 │220 │
       └────┴────┴────┴────┴────┘
```

记住三个规则：

1. 左上角是 `(x=0, y=0)`。
2. X 越大，位置越靠右。
3. Y 越大，位置越靠下。

**宽为 5，X 的有效范围是 0～4；高为 4，Y 的有效范围是 0～3。**

还有一个写代码时容易混淆的地方：

```csharp
// 我们定义的二维数组采用 [行, 列]
// 图像坐标通常写作 (x, y)

byte value = gray[y, x];
```

比如读取 `(x=3, y=1)`：

```csharp
byte value = gray[1, 3]; // 30
```

### 4. 分辨率与内存是什么关系？

一张 `1920 × 1080` 的图片，表示：

```text
宽：1920 像素
高：1080 像素

总像素数：1920 × 1080 = 2,073,600
```

如果它是 8 位单通道灰度图，每个像素占 1 字节，那么**仅像素数据**约占：

```text
2,073,600 字节 ≈ 1.98 MiB
```

实际内存还可能包含行填充等开销。保存成 PNG、JPEG 后，文件大小也不能直接这样计算，因为文件可能经过压缩。

另一个重要概念：**像素数量本身不能告诉你物体有多少毫米。** 同样宽 100 像素的物体，在不同拍摄条件下，实际尺寸可能不同。

### 5. 今天的动手任务

直接用 C# 控制台程序完成，不需要先安装视觉库：

```csharp
byte[,] gray =
{
    { 220, 220, 220, 220, 220 },
    { 220,  30,  30,  30, 220 },
    { 220,  30,  30,  30, 220 },
    { 220, 220, 220, 220, 220 }
};

int height = gray.GetLength(0);
int width = gray.GetLength(1);

Console.WriteLine($"宽：{width}，高：{height}");
Console.WriteLine($"像素总数：{width * height}");

for (int y = 0; y < height; y++)
{
    for (int x = 0; x < width; x++)
    {
        Console.Write($"{gray[y, x],4}");
    }

    Console.WriteLine();
}
```
